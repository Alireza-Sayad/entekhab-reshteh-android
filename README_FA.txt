پروژه اندروید انتخاب رشته آفلاین
================================

طراحی موبایل
------------
این نسخه عمداً Landscape (افقی) است، چون هسته برنامه یک لیست 150 ردیفی است.
برای اینکه صفحه شلوغ نشود، جدول اصلی فقط این ستون‌ها را نشان می‌دهد:
اولویت، کدرشته، رشته، دانشگاه، دوره، حذف

برای دیدن استان، نوع پذیرش، نیمسال، جنسیت و توضیحات، روی خود ردیف بزنید تا پنجره جزئیات باز شود.
این روش روی گوشی از جدول 10 ستونه خیلی خواناتر است.

قابلیت‌ها
---------
- کاملاً آفلاین
- دیتابیس majors.db داخل APK
- 150 اولویت ثابت
- درج مستقیم در هر جایگاه حتی اگر جایگاه‌های قبلی خالی باشند
- اگر جایگاه پر باشد، انتخاب‌های پایین یک خانه شیفت می‌خورند
- کدرشته تکراری از جای قبلی حذف و به اولویت جدید منتقل می‌شود
- حذف فقط همان ردیف را خالی می‌کند
- ذخیره خودکار انتخاب‌ها روی گوشی
- لمس هر ردیف برای نمایش اطلاعات کامل
- خروجی PDF آفلاین (در APK با fpdf2)

نکته PDF
--------
نسخه اندروید برای PDF از فونت فارسی موجود در خود Android استفاده می‌کند.
در اکثر گوشی‌های امروزی Noto Arabic وجود دارد.

ساخت APK
--------
Buildozer به شکل استاندارد روی Linux ساخته می‌شود. در Windows راحت‌ترین روش WSL2 است.

1) WSL/Ubuntu را نصب کنید.
2) پروژه را داخل فایل‌سیستم Linux کپی کنید، مثلا:
   ~/entekhab_resht_android

3) در Ubuntu:
   sudo apt update
   sudo apt install -y python3-pip python3-venv git zip unzip openjdk-17-jdk autoconf libtool pkg-config zlib1g-dev libncurses5-dev libncursesw5-dev cmake libffi-dev libssl-dev

4) یک venv بسازید:
   python3 -m venv .venv
   source .venv/bin/activate

5) Buildozer را نصب کنید:
   pip install --upgrade pip
   pip install buildozer cython

6) APK را بسازید:
   buildozer android debug

بار اول حجم زیادی از Android SDK/NDK دانلود می‌شود و زمان می‌برد.
بعد از پایان، APK داخل پوشه bin ساخته می‌شود.

فایل اصلی:

دیتابیس:

نکته مهم
---------
